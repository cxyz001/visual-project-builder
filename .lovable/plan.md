# 智慧物流可视化大屏（4 个页面）

说明：我无法直接写入你电脑的 `D:\project\001`。项目会在 Lovable 里生成并在右侧预览中直接运行；完成后可通过 GitHub 同步或下载代码，放到 `D:\project\001`，再执行 `npm install && npm run dev` 本地运行。

## 整体风格
- 浅色玻璃拟态（半透明白卡片 + 模糊背景）、品牌蓝主色、青色辅助、绿色状态点
- 顶部导航：404DESIGN Logo、四个标签（运营总览 / 运输车辆 / 仓储货架 / 货物追踪）带蓝色下划线、"DEMO 演示数据"标记、实时跳动的模拟时间
- 页面底部版权条；切换页面带淡入过渡（参考视频）

## 页面
1. 运营总览 `/`：全屏等轴测仓库插画背景；标题"让每一件货物的流转清晰可见"；左侧"今日作业概览 13,005 件 + 折线"、"关键指标"（准时发运率、在库货物、作业车辆、待处理预警）；场景上 4 个可点击热点卡片（智能货架、运输卡车、传送带货箱、搬运机器人）分别跳转对应页面；底部"设备在线率 98.2%"、"小时吞吐趋势"双柱图、"作业动态"时间线
2. 运输车辆 `/trucks`：卡车 TRK-2048 侧视图，车厢内 18 个货箱格（可点击查看）；右侧车辆概况（沪A·8F62K、装载进度条、件数/重量、运输路线）；下方车辆切换卡片（TRK-2048/2051/2063/2072）、装箱清单表、任务进度步骤
3. 仓储货架 `/racks`：货架 A-03 正视图，4 列×3 层货位，悬停弹出货箱信息、空箱标记；右侧货架状态（91.7% 利用率等）；下方货架切换卡、库位货物表、货品分布进度条
4. 货物追踪 `/parcel`：货箱 BX-8472 大图；3 个指标卡（24 件、17.2kg、0.108m³）；货箱档案；流转轨迹时间线；包装与装载；关联作业对象（链接到卡车页）；下方货箱切换列表

所有数据为前端模拟数据，切换卡车/货架/货箱会联动更新页面内容。

## 技术细节
- TanStack 路由：`index.tsx`、`trucks.tsx`、`racks.tsx`、`parcel.tsx`，共享顶栏放在 `__root.tsx`，每页独立 head 标题
- 图片用 AI 生成：等轴测仓库场景、侧视卡车（车厢留空用 HTML 叠加格子）、蓝色货架、纸箱、小缩略图
- 图表用 recharts；模拟数据集中在 `src/data/mock.ts`
- 设计 token 写入 `styles.css`（oklch），字体用 Noto Sans SC + Space Grotesk
